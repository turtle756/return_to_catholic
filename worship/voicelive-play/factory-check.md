# 공장 프리셋 실제 설정 기록

제조사가 각 프리셋의 효과 구성을 공개하지 않아서 기기에서 직접 확인한 내용을 적는다.

확인 방법: 다이얼로 번호를 띄우고, 효과(EFFECTS) 버튼을 누른 뒤 ◀▶로 7페이지를 넘기며 Control과 Style을 본다. 헤드폰을 꽂으면 집에서도 소리를 들어볼 수 있다 (MIX → Headphone Level).

## 양식

OFF인 페이지는 OFF만 적고, ON/HIT인 페이지만 스타일과 값을 적는다.

```
[번호] 이름
µMod: OFF
Delay: ON / 스타일 / Feedback
Reverb: ON / 스타일 / Level / Decay
Harmony: HIT / 스타일 / Level
Double: OFF
HardTune: OFF
Transducer: OFF
느낌: (좋다 / 별로 / 메모)
```

## 확인할 번호

필수: 7, 160, 161, 164
여유 있으면: 9, 162, 165, 181, 203, 206
